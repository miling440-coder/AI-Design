# 上传参考片的动作拆解与 v3 改动

参考片时长 119.026 秒，1920×1080、30 fps。参考片只用于观察动作、构图与转场，成片的元素重新绘制。

## 观察

- 0–约 1.5 秒：巨大前景酒杯碰杯并退走；背景多人举杯，前后景的运动幅度不同。
- 约 1.5–3.5 秒：人物接连离开或变成微粒，灯光变冷；不是整张图一起透明淡出。
- 约 3.5–4.5 秒：镜头推进再交给年节餐桌，主物件变化明显。
- 约 8–12 秒：碎片和粒子交接大标题，再返回冷清客厅。
- 约 19–24 秒：热闹画面被放入一张前景“滤镜”，滤镜碎裂后露出底层空房间。
- 约 27–53 秒：吊灯开始摆动，多只手臂向它伸出；光照在“想要、痛苦、无聊”间改变，最后交接钟面。
- 后半段：人物的增减、分屏、门、画作、心口光点依次承担文案含义，背景仍有次要运动。

## 对当前作品的判断

v2 的大部分动作在小手机、小通知和窗帘内，单看动作数量无法代表观看感受。开头需要占据主体面积的动作，后面的每段也需要明确的视觉事件和交接。

## v3 实施

0–4.5 秒前景碰杯、退场、钥匙接镜；4.5–12 秒三个目标交替移入、缩小、退走，得到后的光亮衰退。12–21 秒大问题浮现并化为细粒，人物散场。21–42 秒加入伸手追逐、短暂满足、新目标接力。42–59 秒大通知接连压入、手机短视频滑动与耳机节律，随后全部退出。59–77 秒上菜的碗从前景入桌，烟花与人物消散留下空镜。77–84 秒未来之门远去，灯光退出。84–104 秒同一客厅出现安坐的人，胸口微光缓慢呼吸，运动强度逐渐降低。

字幕保持整句同步出现；无配音、无背景音乐、无音效。
